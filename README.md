# Data Quality Engine Core 🛡️

![Python](https://img.shields.io/badge/Python-3.9+-blue.svg)
![License](https://img.shields.io/badge/License-MIT-yellow.svg)

High-performance **Business Rules Validation Engine** for enterprise-grade data quality analysis.

---

## 🚀 Key Features

- Automated execution of business validation rules  
- Robust data cleaning and normalization  
- Executive-ready reporting with metrics  
- Modular and extensible architecture  

---

## 🛠️ Tech Stack

- **Language:** Python 3.9+
- **Data Processing:** CSV (Pandas-ready)
- **Cloud Ready:** AWS / Azure compatible
- **Architecture:** Batch processing pipeline

---

## 📋 How It Works

1. **Ingestion** – Load structured data from CSV  
2. **Cleaning** – Normalize and validate raw data  
3. **Validation** – Apply pricing and integrity rules  
4. **Reporting** – Generate executive summaries  

---

## 🔧 Installation

### Requirements
- Python 3.9+
- pip

### Setup

```bash
git clone https://github.com/juanjosetrujillocardozo/Data-Quality-Engine-Core.git
cd Data-Quality-Engine-Core
pip install -r requirements.txt
```

▶️ Run the Engine
Ejecute el motor con el siguiente comando desde la raíz del proyecto:

python src/analysis.py data/products.csv

El reporte se generará automáticamente en el archivo report.md.
